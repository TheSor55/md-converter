========================================================================
   คู่มือการใช้งานเครื่องมือแปลงไฟล์เป็น Markdown (MD Converter)
========================================================================

โปรเจกต์นี้สำหรับแปลงไฟล์เอกสาร (PDF, DOCX, PPTX, XLSX, TXT, CSV) 
ให้เป็น Markdown (.md) เพื่อช่วยลดการใช้ Token ของ AI ได้สูงสุดถึง 70% - 90%

มีให้เลือกใช้งานได้ 2 รูปแบบตามความสะดวกของคุณ:

------------------------------------------------------------------------
รูปแบบที่ 1: ใช้งานผ่านหน้าเว็บเว็บออฟไลน์ (แนะนำที่สุด - ไม่ต้องติดตั้งอะไรเลย)
------------------------------------------------------------------------
ใช้งานง่ายและเร็วที่สุด ไฟล์ทั้งหมดจะถูกประมวลผลบนเบราว์เซอร์ของคุณโดยตรง

วิธีใช้งาน:
1. ดับเบิ้ลคลิกที่ไฟล์ "MD_Converter.html" เพื่อเปิดโปรแกรมขึ้นมา
2. ลากไฟล์เอกสารหลายๆ ไฟล์มาวางลงในพื้นที่สีเทา (Drag & Drop) หรือกดปุ่ม "เลือกไฟล์"
3. กดปุ่ม "แปลงเลย" 
4. ระบบจะทำการคำนวณและพรีวิวตัวอย่าง รวมถึงแสดงร้อยละการประหยัด Token ทันที
5. คุณสามารถกดคัดลอก (Copy) หรือกดดาวน์โหลดไฟล์ .md ออกมาใช้งานได้ทันที

*หมายเหตุ: เครื่องคอมพิวเตอร์ของคุณต้องเชื่อมต่ออินเทอร์เน็ตในการเปิดใช้งานครั้งแรกเพื่อดึงปลั๊กอินประมวลผล*

------------------------------------------------------------------------
รูปแบบที่ 2: ใช้งานผ่านโปรแกรมอัตโนมัติ (สคริปต์ Python ในเครื่อง)
------------------------------------------------------------------------
เหมาะสำหรับเครื่องที่มี Python และต้องการรันแปลงไฟล์ทั้งหมดในโฟลเดอร์แบบอัตโนมัติ

วิธีตั้งค่าและติดตั้งเมื่อนำไปรันที่เครื่องใหม่:
1. ดาวน์โหลดและติดตั้ง Python เวอร์ชัน 3.10 ขึ้นไป (ติดตั้งและติ๊กเครื่องหมาย "Add Python to PATH" ด้วย)
2. เปิด Command Prompt (cmd) ขึ้นมาแล้วเข้าไปในโฟลเดอร์นี้
3. พิมพ์คำสั่งติดตั้งไลบรารีเสริม:
   pip install -r requirements.txt

วิธีใช้งาน:
- [วิธีง่าย] ลากโฟลเดอร์งานวิชาการที่คุณต้องการแปลง มาวางใส่ทับไอคอนไฟล์ "แปลงทั้งหมด.bat" 
  ระบบจะแปลงเอกสารในโฟลเดอร์นั้นเป็น .md ให้อัตโนมัติและเก็บไว้ที่โฟลเดอร์ output/
- [วิธีเปิดเมนู] ดับเบิ้ลคลิกไฟล์ "แปลงทั้งหมด.bat" 
  เลือกหมายเลข 2 แล้วเอา Path โฟลเดอร์มาวาง เพื่อสั่งแปลงได้เช่นกัน

*ระบบมี Incremental Conversion จะแปลงเฉพาะไฟล์ใหม่เท่านั้น หากเคยแปลงไปแล้วจะทำการข้ามทันที*
